Native Django integration

  1. toggly_django.apps.TogglyConfig reads the TOGGLY settings dictionary and initializes the shared client.
  2. Django session and authentication middleware establish the user.
  3. Sample context middleware sets the Order before the native middleware’s helper can cache it.
  4. TogglyMiddleware attaches request.toggly.
  5. Native decorators, template tags and toggly_context evaluate the current request.

Worker ownership

The native AppConfig supplies startup, but no shutdown hook. The sample closes its owned client at process exit and Gunicorn worker exit. Gunicorn does not preload the application, so workers do not inherit background threads.

Ordinary management commands skip network initialization. The no-key path uses a public MemorySnapshotProvider fixture; live startup keeps the actual AppConfig client and signed definitions. No request creates another ordinary definition client.
