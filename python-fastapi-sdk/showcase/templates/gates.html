Variant name and configuration

A boolean answers whether a feature is enabled. An experiment can also assign a named variant and configuration. Baseline flags need not have an assignment.

This explicit action creates an isolated async client with known user context before initialization, reads get_variant, then closes it. Ordinary pages share the worker client. The FastAPI helper itself has no variant API.

config = TogglyConfig(
    app_key=app_key, environment='Production',
    enable_variants=True, identity=context.identity,
    variant_groups=context.groups, variant_claims=context.claims,
    disable_background_refresh=True,
)
client = AsyncTogglyClient(config)
try:
    await client.init()
    assigned = await client.get_variant('new-dashboard')
finally:
    with anyio.CancelScope(shield=True):
        await client.close()
