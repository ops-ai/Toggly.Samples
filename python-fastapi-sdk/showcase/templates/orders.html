An entity describes the business object, independently of who is using it. ExpressCheckout checks this Order's Vip property.

DemoContextMiddleware sets request.state.toggly_entity before the native helper caches context. Changing that state after a helper read would not rebuild it.

)

client.is_enabled('ExpressCheckout', context=context.with_entity(order(True)))
client.is_enabled('ExpressCheckout', context=context.with_entity(order(False)))
client.is_enabled('ExpressCheckout', context=context.with_entity(None))

with_entity copies the user context; it does not change the shared client. Wrong-kind is a diagnostic: the Python filter checks properties without validating kind, so a wrong-kind VIP also returns ON. Supply the correct Order.
