Gate the action on the server

require_feature runs before POST /submit/ changes a reversible session counter. Hiding a button alone cannot protect an endpoint. CSRF is checked separately.

@pages.post('/submit/', dependencies=[
    Depends(checked_form), Depends(require_feature('enhanced-submit')),
])
async def submit(request: Request):
    request.session['submissions'] = request.session.get('submissions', 0) + 1
