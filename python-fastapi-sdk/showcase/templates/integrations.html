Middleware and lifespan

SessionMiddleware → demo principal/Order mapping → TogglyASGIMiddleware → dependencies and endpoints. The native pure ASGI middleware resets its ContextVar in finally, including exceptions and cancelled requests.

TogglyDep provides the same request helper; ContextDep exposes its cached context. Do not pass AsyncTogglyClient to these helpers: they call synchronous methods without awaiting. One sync client serves local evaluations per worker; startup/refresh/close run off the event loop. Remote variants use an explicitly isolated async client only for their action.

feature_switch returns a generic callable. The sample's typed wrapper passes Request to that native switch, rather than exposing *args/**kwargs as query parameters. with_feature_context creates a narrower context that drops entity; use explicit with_entity copies for Order examples.
