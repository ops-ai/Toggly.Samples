# Contributing

Thanks for your interest in improving the Toggly samples.

This repository hosts **runnable example apps**. We welcome focused contributions that make samples clearer, more accurate, or easier to run.

## Before you start

1. **Open an issue first** for bugs, new samples, or large docs changes — use the [issue templates](https://github.com/ops-ai/Toggly.Samples/issues/new/choose).
2. **SDK bugs and API questions** belong in [Toggly.FeatureManagement](https://github.com/ops-ai/Toggly.FeatureManagement) or the [docs](https://docs.toggly.io), not here.
3. **Security issues** must follow [`SECURITY.md`](SECURITY.md) (private vulnerability reporting only).

Please wait for maintainer feedback on the issue before opening a large PR.

## Pull requests

- Keep changes focused on **one sample** or a shared repo concern (README, CI, templates).
- Link the related issue in the PR description.
- Update the sample README when setup steps or required flags change.
- Do not commit secrets, credentials, `.env.local`, or local SDK tarballs (`.local-sdk/`).
