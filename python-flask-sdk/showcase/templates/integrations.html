Native Flask integration

Factory and lifecycle

create_app configures Flask-Login, CSRF and Order context before attaching the native Toggly extension. Live mode uses its automatic initializer. Offline mode supplies a public snapshot client and registers it once for the decorators.

One client lives for the worker lifetime. close_client runs at process/worker shutdown, never after an individual request. Gunicorn preload is disabled so clients and background threads start inside each worker.

Try package surfaces

  • FeatureFlagBlueprint: beta-access gate on its registered route.
  • feature_flag_required: actual identity-aware Targeting.
  • feature_gate_required All, Any, negate.
  • Disabled redirect: api-v2 returns here when OFF.
  • Disabled fallback_view: API v1 content when OFF.
  • feature_flag_switch: native API v1 / v2 view selection.
  • feature_variant: visible named-dispatch limitation.

Read showcase/__init__.py, context.py, views.py and the tests in that order. Native toggly.flags is a process-default snapshot; this workshop's snapshot evaluates each key with the current request instead.
